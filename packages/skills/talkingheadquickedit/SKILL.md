# 口播快剪

1. 调用 `readTimeline` 读取当前时间线，优先根据选区和用户描述定位口播片段。片段不明确时先询问。需要导出 MP4 时，工程须有可见的视频轨片段。
2. 对未裁切且未变速的口播片段，按用户要求调用 `tightenTimelineSpeech`。使用 `tighten` 缩短沉默，使用 `speedUp` 加速停顿。等待页面确认，保留原素材。他处片段位置保持原位。
3. 停顿处理结束后用同一片段 ID 调用 `subtitleTimelineSpeech`。此操作需要浏览器支持音频识别。字幕按句或短语切成多条，各有独立起止时间并覆盖处理后的片段区间，可逐条选中修改。已有重叠字幕时请用户先核对。若浏览器识别服务连接失败，请明确说明自动转写未完成，并提出两条兜底：用户给出口播文稿时调用 `subtitleTimelineFromScript` 按句对齐；用户已有 SRT 时，通过素材库导入并加入字幕轨。两种方式都要说明时间轴为按句近似，需用户核对。
4. 用户要求交付 MP4 时，调用 `exportTimelineMp4` 并等待页面确认。报告返回的项目相对路径和各步骤结果。用户取消或工具失败时说明当前进度，避免无条件重试。
5. 当前打开的是 OpenFilm Studio 时，内置时间线的口播工具不可用。说明本期口播快剪按内置时间线验收，Studio 内的同等能力另行验收，请用户切回内置时间线后再继续，不要用 Studio 的片段工具冒充完成。
